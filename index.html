CONTROLS & SETTINGS

KEYBOARD & MOUSE

  • A / D or ← / → : Move Left / Right
  • W / SPACE or ↑ : Jump / Climb Up
  • S or ↓ : Crouch / Crawl / Drop Down
  • SHIFT : Sprint (Noisier)
  • E or CTRL : Grab / Push / Pull / Flip Switch
  • F or L : Flick Lighter / Lantern
  • LEFT CLICK : Aim & Throw Distraction (When holding bottle)
  • ESC or P : Pause Menu

TOUCH (MOBILE / TABLET)

  • ▲ / ▼ / ◀ / ▶ : D-Pad Move / Climb / Crouch
  • JUMP : Spring & Vault over Gaps
  • GRAB : Push / Pull Crates & Levers
  • RUN : Fast Sprint
  • LIGHT : Toggle Lighter / Lantern
  • THROW : Toss Distraction Bottle
